PASS if the response speaks to the user in a few complete reports rather than a running commentary: a proposed-model report opening "A proposed model is being built" that holds the map table (object and its rules, what it can do, who may call it), a paragraph per object, roles, what was set aside, every feature with its scenarios in plain English, the assumptions, and the build ahead with the reason for each step; and between reports nothing but the scope round, one line naming the objects, or a question only the user can answer. FAIL if it narrates step by step (lines about reading references, writing files, fixing typos, or what comes next), if the report omits the scenarios or the map, or if it calls the model "settled". Quote what you relied on.

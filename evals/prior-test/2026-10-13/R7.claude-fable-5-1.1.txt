Reboot ships a test harness in `reboot.aio.tests` that boots a real (local, in-process) Reboot instance for you, so tests exercise your actual servicers through generated client stubs rather than mocks. The usual pattern is `unittest.IsolatedAsyncioTestCase` (or pytest-asyncio) with start/stop in setup/teardown.

```python
import unittest

from reboot.aio.applications import Application
from reboot.aio.tests import Reboot

from bank.v1.bank_rbt import Account          # generated by `rbt generate`
from bank.servicers import AccountServicer     # your servicer implementation


class TestAccount(unittest.IsolatedAsyncioTestCase):

    async def asyncSetUp(self) -> None:
        self.rbt = Reboot()
        await self.rbt.start()

    async def asyncTearDown(self) -> None:
        await self.rbt.stop()

    async def test_deposit_and_balance(self) -> None:
        # Bring up your application (all its servicers) inside the test.
        await self.rbt.up(Application(servicers=[AccountServicer]))

        # An "external" context acts like an outside client calling in.
        context = self.rbt.create_external_context(name=f"test-{self.id()}")

        account = Account.ref("alice")
        await account.open(context, initial_balance=0)
        await account.deposit(context, amount=25)

        response = await account.balance(context)
        self.assertEqual(response.amount, 25)
```

Key points:

- `Reboot()` + `await rbt.start()` / `await rbt.stop()` manage the local runtime (older releases used `rbt.up(servicers=[...])` instead of wrapping in `Application`).
- `rbt.up(...)` registers your servicers; you can call it multiple times to simulate multiple apps/restarts, and `rbt.down()` to stop one.
- `create_external_context(...)` gives you a context to call state methods via the generated `*_rbt` stubs (`Account.ref("id").method(context, ...)`).
- Because it's the real runtime, you can test transactions, workflows, and persistence behaviour (e.g. restart an app and assert state survives).
- Run with `python -m unittest` or `pytest` (with asyncio support) after `rbt generate` has produced the stubs.

Confidence: medium

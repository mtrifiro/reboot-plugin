PASS if, before designing, the response asks the user one round of scope questions with options (which parts of the domain the first version covers, who uses it and in which roles, what it must never get wrong, whether the data is kept), or, where the session says no one can answer, states the answer it takes for each of those, and then says a simple, fast prototype of that scope goes up first. FAIL if it designs or builds without asking or stating the scope, asks open-ended questions with no options, or asks more than one round before the prototype. A question about which kind of app to build counts neither way. Quote what you relied on.

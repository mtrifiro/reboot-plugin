PASS only if the design includes a visual brief that names one accent color and its source (a brand the user or organization actually has, or an explicit statement such as "Reboot default, no brand supplied"), a type choice, and a primary view for the main screen with a reason tied to the task (for example a feed of recent kudos, a leaderboard, or a ranked list). FAIL if there is no visual direction, the main screen's view is not named, or the accent's source is claimed from someone who never gave one.
